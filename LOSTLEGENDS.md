# Pokémon: Lost Legends

A ROM hack of Pokémon Crystal built on the [pokecrystal](https://github.com/pret/pokecrystal) decompilation.

## Build

Requires RGBDS 1.0.0 or newer. See `.github/workflows/build.yml` for the verified toolchain,
or run the build in GitHub Actions and download the ROM artifact.
